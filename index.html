How to use the studio

Choose a stitch from the palette, then double-click the canvas to place it. Double-click a palette symbol to place one in the visible board's centre.

Choose Select to drag individual stitches or drag across empty space to box-select several. Drag a selected stitch to move the selection together. Duplicate to repeat stitches with the same properties.

Use the Hand tool to pan the whiteboard, or your mouse wheel to zoom. Row and Circular guides are optional alignment aids and are not included in exports.

Save project downloads an editable file that you can open later. Export PNG or SVG for a finished diagram.
